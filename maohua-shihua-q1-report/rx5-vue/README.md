# RX5 洛神座舱 HMI（Vue3 + TailwindCSS）— 使用说明

## 启动

零构建依赖，静态托管即可：

```bash
cd rx5-vue
python3 -m http.server 8080    # 或 npx serve -l 8080
# 车机WebView / 手机 / 平板 浏览器打开 http://<host-ip>:8080/
```

文件结构：
```
rx5-vue/
├── index.html   入口 + Tailwind 深色座舱设计系统(低反光高对比)
└── hmi.js       Vue3 全部逻辑: 状态store + 9页面组件 + Dock + 语音 + 行车安全
```

## 车机安全交互

- **D挡**：全屏 DriveLock 遮罩(黑色85%) → 视频暂停、仅音频可播、状态栏显示"行驶中"
- **P挡**：自动解锁娱乐
- **R挡**：泊车雷达激活、距离递减播报
- 弹窗全部置底或左上角，**不遮挡导航**；按钮热区≥48px；页面切换带车载过渡动画(pop/slide)

## 生产对接（预留接口）

统一指令出口 `sendCmd(service, op, value)`（hmi.js 顶部）：

```js
// 替换为: vehicleBridge.send({service:'hvac',op:'SET_TEMP',value:24,origin:'touch'})
// 通道: WebSocket → TBOX网关 → CAN总线 (UDS / ISO15765-4 500kbps)
```

模拟数据源为 `car` reactive 对象，生产映射 CAN 订阅：
```js
can.on('speed', v => car.speed = v)      // 10Hz
can.on('tire',  a => car.tire = a)       // 4轮
```

高德地图接入：把 NavPage 地图容器替换为 AMap JSAPI 容器（预留 HTMLElement id）。

## 车规适配

- 10.4" 竖屏优先 flex 布局；横屏自动改 Dock 竖排
- 深色 #0E1116 底 + #4FC3F7 点缀，浅色一键切换（对比度 AA）
- 无捏合/双击等复杂手势；弹窗轻量化；所有交互触控可达
